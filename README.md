# Imagina en IT

Material de la sección **Imagina en IT** del canal de YouTube [Arce Data Lab](https://arcedatalab.com).

Cada episodio cuenta un problema real de tecnología como una historia: *imagina que…*. Aquí tienes los datos, los prompts y el código para reproducirlo tú.
