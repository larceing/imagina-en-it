# Episodio 2 · Imagina que te creas tu perfil de LinkedIn

Plantillas para arreglar los tres errores del vídeo: el titular, el *acerca de* y no aparecer.

## 1. Titular

Fórmula: **qué haces + para quién + con qué**.

| Nivel | Ejemplo |
|---|---|
| Mal | Analista de datos en búsqueda activa |
| Mejor | Analista de datos · Power BI y SQL |
| Bien | Convierto el Excel de tu empresa en dashboards que se entienden · Power BI y SQL |

Plantilla:

```
Ayudo a [quién] a [resultado] con [herramientas]
```

Comprueba que aparecen las palabras clave por las que te buscarían (Power BI, SQL, Python, Excel…).

## 2. Acerca de

Escríbelo para un cliente, no para un tribunal. Las dos primeras líneas son las que se ven antes de «ver más».

```
[Problema que resuelves, en una frase].
[Qué haces tú al respecto, en una frase].

Un ejemplo: [proyecto real o inventado] → [resultado con cifra].

Trabajo con [herramientas].

Si quieres [beneficio], escríbeme.
```

Ejemplo:

> Muchas empresas tienen los datos, pero no los miran, porque nadie se los ha puesto fáciles. Yo me dedico a eso.
>
> Un ejemplo: automaticé el informe semanal de ventas de una tienda y pasó de cuatro horas a diez minutos.
>
> Trabajo con Power BI, SQL y Excel.
>
> Si quieres revisar tus informes, escríbeme.

## 3. Experiencia: tareas → logros

| Tarea (evitar) | Logro (usar) |
|---|---|
| Elaboración de informes | Automaticé el informe semanal de ventas: de 4 horas a 10 minutos |
| Mantenimiento de bases de datos | Eliminé duplicados en la tabla de productos y el margen dejó de inflarse un 2,5 % |

## 4. Rutina de 30 minutos a la semana

- [ ] 10 comentarios útiles en publicaciones de tu sector
- [ ] 1 publicación: algo que hiciste o aprendiste (antes/después, un error, un truco)
- [ ] Responder los comentarios de tu publicación el primer rato
- [ ] Conectar siempre con una nota de una línea
- [ ] Mirar las estadísticas: apariciones en búsquedas y visitas

## 5. Nota de conexión

```
Hola [nombre], he leído tu publicación sobre [tema] y me ha parecido muy útil. Trabajo en [lo tuyo]; me gustaría seguir lo que compartes.
```

## Cuidado

Nunca publiques datos de clientes. Usa datos inventados (como los de Ciclos del Sur en este repositorio) o anonimízalo todo.
